## Featured Project — Platform Accounting Automation

A real-world case study examining the accounting operations of a large-scale digital marketplace processing hundreds of millions of transactions annually. The project diagnosed a fragmented, spreadsheet-heavy accounting operation and delivered a working cloud-based solution to replace it.

**What was built:**
- A modular ETL data pipeline using **DBT** and **Google BigQuery**, transforming raw platform transaction data into auditable financial accounting data across five structured layers (staging → intermediate → enrichment → aggregation → presentation)
- A **Python CLI application** (`gforevpy`) automating journal entry preparation, account reconciliations, and audit support — with built-in data quality checks and reviewer workbooks
- **Looker Studio** dashboards for stakeholder reporting, replacing ad hoc spreadsheet requests with live, on-demand insights
- Continuous data integrity monitoring using **Google App Scripts**, with automated daily checks and team alerts

**Results:**
- Processing time for journal entries reduced from ~1 hour to under 5 minutes per account
- Reconciliation time reduced from up to 3 hours to under 5 minutes per account
- 350+ labour hours saved annually
- All functional and non-functional requirements met

**Stack:** Python · SQL · DBT · Google BigQuery · Google App Scripts · Looker Studio · Git
