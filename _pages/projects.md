# [💲 Using Machine Learning to Assess Going Concern Risk](https://thabanibiyela.github.io/aml-going--concern/)

***Python · scikit-learn · Pandas · Logistic Regression · Random Forest***

Going concern is one of the most consequential judgements an auditor makes — and one of the hardest to get right. This project explored whether machine learning could support that judgement by predicting bankruptcy risk from financial statement data.

Using the Taiwanese Bankruptcy Prediction dataset (6,800+ companies, UCI), the project built and evaluated a pipeline of classifiers — including Logistic Regression, Decision Trees, and Random Forest — optimised for recall and AUC given the class imbalance inherent in bankruptcy data. Feature selection combined automated Random Forest importance scoring with professional accounting judgement to reduce noise and improve interpretability.

Tree-based classifiers came out on top, consistent with the broader literature on financial distress prediction.

# [💬 Intrusive Thoughts](https://thabanibiyela.github.io/intrusive-thoughts-api/)

***Express · Mongoose · JSON Web Token · MongoDB · OAuth token authentication · Bcryptjs · JSON Web Token · Body-Parser***

A social networking API where users — called thinkers — post their most intrusive thoughts for others to browse, score, and comment on. The more intrusive, the better. Intrusive Thoughts is a REST API built with Node.js and Express, backed by MongoDB. It implements OAuth-style token authentication, role-based access control, and a full suite of CRUD operations across three data models.
